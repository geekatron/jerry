# PROJ-0039: Nuclear Engineer SOPs -> Claude Code Skill

## Objective

Research nuclear engineering standard operating procedures (SOPs) used to maintain critical energy infrastructure (nuclear power plants), with the goal of distilling these operational practices into a Claude Code skill for systematic procedure-based work.

## Constraints

- **No LLM training data**: All research must come from web search (WebSearch/WebFetch)
- **Source validation**: Every creator step must be adversarially reviewed for source quality
- **Skill focus**: Research findings must be oriented toward building a Claude Code skill
